# ATB

Static site published to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

- `site/index.html` — home page with links to sub-projects.
- `site/<sub-project>/index.html` — one folder per sub-project.

Sub-projects:

- `site/darkmoon-storage-box/` — Darkmoon Storage Box guide and ticket calculator.

To add a sub-project: put it in `site/<name>/`, add a button to `site/index.html`, push.
